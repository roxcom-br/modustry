## About

**Modustry** is a web platform built to make discovering **Mindustry mods and texture packs** easier, faster, and more organized.

Instead of browsing repositories manually, users can explore a curated interface with mod details, metadata, descriptions, download information, and useful links in one place.

The goal of Modustry is to improve the experience of finding, viewing, and sharing community-made Mindustry content.

---

## Features

- Browse Mindustry mods and texture packs
- View detailed information about each mod
- Access repository, download, and metadata links
- Search and explore community content
- Clean and responsive interface
- Built with modern web technologies

## Getting Started

Follow the steps below to run the project locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm, pnpm, yarn, or bun

### Installation

1. Clone the repository:

```sh
git clone https://github.com/roxcom-br/modustry.git
```

2. Enter the project folder:

```sh
cd modustry
```

3. Install dependencies:

```sh
npm install
```

4. Configure the API URL:

```env
export API_URL="YOUR_API_URL"
```

6. Start the development server:

```sh
npm run dev
```

7. Open the project in your browser:

```txt
http://localhost:3000
```
